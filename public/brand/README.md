# amortiza.me Brand Assets

- `logo.png`: optimized full logo supplied by the project owner (1000 x 211).
- `symbol.png`: optimized standalone symbol (512 x 512).
- Assets remove transparent margins and resize proportionally. Unused source exports are not kept in the repository root.
- `src/app/favicon.ico` and `src/app/apple-icon.png` are generated from the standalone symbol.
- The UI displays the full logo in white in dark mode via a CSS monochrome filter.
